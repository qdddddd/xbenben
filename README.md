# xbenben

An installable, offline poker session log with local storage, analytics7 imports, CSV exports, and complete file backups for iCloud Drive / Files.

**[Open xbenben](https://qdddddd.github.io/xbenben/)**

- [Run, test, build and install on iPhone](app/README.md)
- [Verification results and design decisions](app/PARITY.md)

The app lives in `app/`. `Ledger.dc.html` and the other original design files are preserved as read-only references. Private poker exports, the local prompt and verification screenshots are excluded from this repository and the published site.
